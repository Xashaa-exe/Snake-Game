# Snake-Game
A Python Snake Game using Pygame demonstrating OOP, dynamic UI, and cryptography concepts.  ## Features - **Data Security:** SHA-256 salted hash verification to prevent local score tampering. - **Dynamic UI:** Smooth color-shifting score text via sine wave logic. - **Gameplay:** Screen shake, golden apples, Pause &amp; Settings menu.
Snake Game in Python. Detailed gameplay videos & screenshots are available in the Wiki section.
